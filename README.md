# Money Tracker 💸

A simple, fast, and responsive personal money tracker built using only vanilla **HTML5**, **CSS3**, and **JavaScript**.

All data is stored directly in your browser using `localStorage` — no backend, no server, no database, and no login required.

## Features

- **Summary at a Glance**: Prominently view your total amount spent and total expense count at the top.
- **Add Expenses**: Easily record spending with title, amount, and date (defaults to today).
- **Neat Expense List**: Clean chronologically ordered list with formatted currency and readable dates.
- **Edit Expenses**: Update any past expense directly with an intuitive edit modal.
- **Delete with Confirmation**: Deleting an item prompts for confirmation to avoid accidental clicks.
- **Live Search**: Instantly filter your spending list by keywords, dates, or amounts.
- **Empty States**: Friendly illustration and guidance when no expenses are recorded or when search filters yield no results.
- **Mobile-First & Responsive**: Designed to look and feel like a modern app on both mobile phones and desktop browsers.
- **Persistent Storage**: Data stays saved locally in your browser across tab reloads and sessions.

## Tech Stack

- **HTML5**
- **CSS3** (CSS Variables, Flexbox, Animations)
- **Vanilla JavaScript** (ES6+, LocalStorage API)

## Getting Started

Simply clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/DEB-LA/MoneyTracker.git
cd MoneyTracker
open index.html
```

Or just double-click `index.html` on your computer!
